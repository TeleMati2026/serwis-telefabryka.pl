# Serwis Telefabryka

Gotowy internetowy cennik GSM z panelem administratora.

## Funkcje
- publiczny cennik, wyszukiwarka i filtr marek,
- logowanie administratora przez Supabase Auth,
- dodawanie, edycja, ukrywanie i usuwanie pozycji,
- zabezpieczenie Row Level Security: klienci tylko czytają,
- brak Vite, npm i procesu kompilacji,
- działa na GitHub Pages.

Instrukcja uruchomienia znajduje się w `START-TUTAJ.txt`.
